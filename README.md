Clínica Veterinária

Sobre o trabalho

Este trabalho apresenta a modelagem de um banco de dados para uma
clínica veterinária.

O projeto foi feito a partir do cenário proposto na atividade e mostra
as entidades, os relacionamentos, o esquema do banco e o script SQL.

Entidades

• Clientes
• Animais
• Veterinários
• Consultas

Relacionamentos

• Um cliente pode ter vários animais.
• Um animal pertence a um cliente.
• Um animal pode ter várias consultas.
• Um veterinário pode realizar várias consultas.
